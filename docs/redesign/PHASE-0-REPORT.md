### What the baseline found in the OLD UI
1. **Sideways scrolling on phones.** Marketplace home, login, register, reset-password and the booking dialog render 483 to 488 px wide at a 375 px viewport (997 px at 768). The redesigned marketplace has **not** been checked for this yet. Check it in the Phase 6 / 7 pass at 320, 375, 768.

3. Arabic pages with Latin digits for dates, money and counts (what the formatter fixes).

## Terminology sheet
`docs/redesign/MASAR-Terminology-Sheet.md` and `.csv` (same rows; the CSV opens in Excel for the reviewer). Generated by `scripts/gen-terminology-sheet.cjs` from every English/Arabic pair in `src`. 907 rows: status labels 29, navigation and shell 21, design-system chrome 37, company dashboard 319, passenger marketplace 461, other 40. Each row has a Decision and a Reviewed Arabic column. 16 rows are flagged as empty-state or guidance sentences; 3 rows are same-as-English (phone and ID placeholders).

Gaps: admin and driver screens have no Arabic at all (English only by decision). Sentences assembled from parts at run time, and text from the database, are not in the sheet. The generator reads source, so it can miss a string written in an unusual shape; the reviewer should also scan the screens.
